# Quick task 261104-w53 — safe lay-phrasing aliases, and no GREEN on a deferred card

## Goal

Close the two visible findings the earlier hardening task deliberately left open
(`.planning/nurse-stress-test/REPORT.md` §6 "if time allows", S2-1 and S2-3), without widening
the substrate and without touching the safety spine:

1. **S2-1 (partial, by design).** Add lay/OPD phrasing aliases to **already-declared**
   discriminators only, so a nurse's own words reach the deterministic matcher instead of

## Decisions

**D1 — aliases are added as data, only where a declared discriminator already means the
phrase.** 30 aliases across 6 discriminators. No new discriminator, no new category, no edit
to `core/matcher.py` (CONVENTIONS §2 open/closed: extend by data, never by working code). Each
phrase was checked in a throwaway probe: it matches its target, matches nothing else, and its
denial ("no <phrase>") matches nothing.

**D2 — the phrases the report logged but that have no SAFE mapping stay unmatched.**

| Rejected phrase | Why (do not add) |
| --- | --- |
| fever, headache, cough, sore throat, diarrhoea, single-episode vomiting, back pain, weakness, feeling unwell, not eating, rash, ear pain, urinary symptoms, dizziness, fall, wound | No declared SATS discriminator exists for them; an alias would invent a category, and "feeling unwell" is the declared E-09 coverage gap |
| `burn` (bare) | Would map a >20 % / facial burn to YELLOW `other_burns` — under-triage, the unsafe direction |
| `fit` (bare) | Fires on "fit for discharge"; `fitting` / `convulsing` / `seizure now` already cover the current-seizure meaning |
| `had a fit` | Ambiguous in time (could be post-ictal or historical) — a RED from a past event |
| `vomiting` (bare) | `persistent_vomiting` asserts *persistence*; a single episode would be over-claimed |
| `eye pain` | Pain is not injury; `eye_injury` is a different clinical fact |
| `chest pane`, `shortnes of breath` | Typos; the deterministic matcher is not a spellchecker and the extraction path is where a typo belongs |

**D3 — the badge reuses the ONE class-mapping helper and the existing grey tokens.**
`_colour_class("DEFERRED")` already yields `colour-deferred` (it lowercases), so no second
class-naming rule appears in Python; the CSS rule reuses `--muted-bg` / `--muted-text`, so no
new token is declared. The badge word itself goes in `copy.py` (the ONE home for user-facing
strings, and the same module that already owns `_DEFERRED_COPY`).

**D4 — the deferred path drops two facts, not the substance.** The colour and target time are
the two things a deferral declines to stand behind; the framing line, the triggered rules with
their citations, the evidence, "Not recorded", the second-look line and the case id all stay.
