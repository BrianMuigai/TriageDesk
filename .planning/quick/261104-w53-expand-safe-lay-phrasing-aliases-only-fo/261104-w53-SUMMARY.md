# Quick task 261104-w53 — safe lay-phrasing aliases, and no GREEN on a deferred card

## One-liner

30 lay/OPD aliases now reach six already-declared discriminators, and the read-only deferred
card shows a DEFERRED badge with no colour or target time instead of anchoring a GREEN.

## What changed

### Task 1 — lay/OPD aliases on existing discriminators (commit `950ccd7`)

- `data/sats_discriminators.yaml`: extended the alias lists of `acute_shortness_of_breath`,
  `chest_pain`, `reduced_level_of_consciousness`, `high_energy_transfer`, `closed_fracture`
  and `abdominal_pain` with 30 lay/OPD phrases. The header now records the policy: lay
  phrasing extends **existing** discriminators only; a phrase with no declared discriminator
  stays unmatched, and no category is invented. No new discriminator, category, label,
  citation or version change.
- `tests/test_matcher.py`: added `_LAY_PHRASING` (phrase → anchor alias) and
  `test_lay_phrasing_matches_its_declared_discriminator`, which derives the expected id from
  the loaded substrate through `_id_for_alias` (never restating an id). Added
  `test_every_declared_alias_matches_through_the_matcher`, the standing sweep that proves the
  expansion shadows no existing alias and keeps leading-negator aliases (`no pulse`,
  `not alert`) positive.
- Unmatched-by-design phrases were re-probed and still defer honestly: `feeling unwell`,
  `fever`, `cough`, `headache`, `burn`, `fit`, `wound`, `dizziness`.

### Task 2 — DEFERRED badge on the read-only card (commit `bb73945`)

- `src/triagedesk/desk/copy.py`: added `_DEFERRED_BADGE = "DEFERRED"` beside `_DEFERRED_COPY`
  (the ONE home for user-facing strings).
- `src/triagedesk/desk/card.py`: `_card_html` branches on the existing `read_only` flag. The
  read-only path renders `<div class="colour-block colour-deferred">` with a `DEFERRED` name and
  emits nothing where "Suggested colour:" / "Target time:" would go. The class is built through
  the existing `_colour_class` helper. The committable path is byte-identical to before. No new
  helper, no payload-contract change, `desk/views.py` untouched.
- `src/triagedesk/desk/static/styles.css`: added `.colour-deferred` reusing `--muted-bg` /
  `--muted-text`; no new custom property or colour literal.
- `tests/test_desk.py`:
  - new end-to-end `test_deferred_card_shows_a_deferred_badge_and_no_colour` drives the genuine
    E-09 fixture, derives the suppressed colour/target from
    `matcher.match_discriminators` + `scorer.score_priority`, asserts the preconditions (so the
    negatives cannot pass vacuously), then asserts the badge is present, the scored colour name
    and swatch class are absent, both fact labels are absent, and the sourced facts (triggered
    rules, evidence, "Not recorded:", "Case:") survive with no gate;
  - the deferred branch of `test_colour_label_accompanies_every_rendered_colour` now pins the
    badge instead of a colour;
  - `test_css_declares_every_substrate_colour_token` excludes `colour-deferred` from the
    swatch-set equality (exclusion derived from `_DEFERRED_BADGE`), because the badge is a
    presentation state, not a substrate colour.
