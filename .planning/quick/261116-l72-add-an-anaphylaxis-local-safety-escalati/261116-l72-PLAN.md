<objective>
Make an acute anaphylaxis presentation escalate to RED as an explicitly labelled **deployment-level
local safety escalation**, kept structurally separate from the SATS transcription.

Purpose: today a patient with facial swelling and throat tightness on normal vitals scores GREEN
("< 4 hours", "Designated area") because the SATS 2012 adult chart has no anaphylaxis, allergic-
reaction, stridor or angioedema discriminator. The system detects the crash (TEWS 8) but not the
anaphylaxis. Inventing a SATS entry would breach CONVENTIONS §1 (data is transcribed, never
invented), so the escalation lives in its own data file with its own citation that states it is not
SATS.

Output: a new sibling data file, one merged loader, a per-category citation source so a local
escalation can never claim SATS provenance, and tests that prove the colour, the citation, the
confidence outcome, the ambiguity path and the untouched SATS transcription.
</objective>
