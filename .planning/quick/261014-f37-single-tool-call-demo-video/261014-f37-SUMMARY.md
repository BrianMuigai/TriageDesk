## Notes / deviations

- The capture/render toolchain (`agg`) is build-time only (`cargo install --git
  https://github.com/asciinema/agg`); it is not a project dependency and no runtime path imports it.
- The public **upload** (G1) remains a human action — the one open submission step.
- Key rendering subtleties encoded in the pipeline: the `ass` burn needs `fps=25` **before** the
  subtitles filter (the agg render is sparse, so a caption would otherwise freeze at the last change),
  and agg trims trailing idle to `--last-frame-duration` (a final visible prompt keeps the close).
