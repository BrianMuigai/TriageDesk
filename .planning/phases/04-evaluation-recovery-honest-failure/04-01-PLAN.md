<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| case fixture -> graph | A fixture's free-text note is untrusted input to `normalize`; the structured golden case is the declared, reviewable extraction. |
| harness -> owned tools | The eval calls the real owned tools in-process; the store seam is injected so no borrowed subprocess or network is reachable. |
| report -> consumer | The report is the sole record of a run; it must be machine-generated and provenance-stamped or it cannot be trusted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Spoofing | evals/report.py | high | mitigate | The report records its `mode` and provenance; an offline (stubbed-model) run is labelled `offline` and can never be presented as a real measured run (Pitfall 16). |
| T-04-02 | Tampering | evals/report.py report_digest | high | mitigate | The digest seals the non-volatile content via `core.hashing.hash_value`; a hand-edited number changes the digest, and the generator in 04-04 refuses a mismatched report. |
| T-04-03 | Information disclosure | evals/report.py serialisation | medium | mitigate | Untrusted complaint text is serialised through the ONE canonical JSON path; it is never string-concatenated into the report (M-13). |
| T-04-04 | Denial of service | evals/runner.py | medium | mitigate | The graph's retry is already bounded; the runner caps runs per case and applies a per-run wall-clock ceiling so a pathological case cannot hang the evaluation. |
| T-04-05 | Repudiation | evals/report.py provenance | high | mitigate | Every report names the model tag/quant, prompt hash, SATS YAML hashes and harness commit SHA, so a run can be reproduced or shown to have varied (D-08). |
| T-04-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new dependency is added: the CLI uses stdlib `argparse` and every other import is already pinned in `uv.lock`; the borrowed server is untouched by this plan. |
</threat_model>
