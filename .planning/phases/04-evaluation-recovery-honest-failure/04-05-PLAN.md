carries no citation, and is treated by `verify()` as "no evidence" — so the graph fail-closes to END with

gate, and enforce the citation contract honestly at the invariant level.

patient — not silence — **so that** the system's core promise holds for every patient, not only the sick ones.

Purpose: the core value (a sourced, confirmable priority in seconds) is unmet for a whole class of routine
presentations; this plan closes that class without weakening the citation invariant for genuinely uncited
priorities. Output: a data-driven baseline citation, a cited TEWS-0 scorer contract, a strengthened INV-1,
and the regression proofs.
</objective>
