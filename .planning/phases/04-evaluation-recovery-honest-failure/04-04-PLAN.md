<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| report -> EVALS.md | The published document must be a projection of the raw report; the one place a fabricated number could enter. |
| analysis -> safety claim | Symmetric accuracy would hide the dangerous direction; the split must stay separate. |
| tampered report -> generator | A hand-edited report must not be silently published. |
| offline report -> measured claim | The offline (stubbed-model) gate report must never be presented as the measured run. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-16 | Tampering | EVALS.md result cells | high | mitigate | The generator is the only writer of the result cells and renders strictly from the report; a test asserts every rendered field equals the report value (Pitfall 16). |
| T-04-17 | Repudiation | evals/analysis.py | high | mitigate | Under-triage and over-triage are reported separately with their case ids, so a defect in one direction cannot be hidden behind a combined accuracy figure (Pitfall 8). |
| T-04-18 | Spoofing | evals/report.py report_digest | high | mitigate | The generator refuses a report whose digest does not recompute, and a test mutates an outcome to prove the digest changes (D-08). |
| T-04-19 | Information disclosure | evals/analysis.py | low | accept | The analysis holds only synthetic case ids and colour outcomes; there is no patient-identifying data to leak. |
| T-04-20 | Denial of service | scripts/emit_evals.py | low | accept | The generator is bounded by the fixed case set; report size is not attacker-controlled in this prototype. |
| T-04-21 | Spoofing | evals/results/report.json | high | mitigate | The report records its `mode`; the measured task asserts `mode: real` with non-zero token counts and real model provenance, and the generator labels the source, so an offline (stubbed-model) report can never be presented as the measured run (Pitfall 16). |
| T-04-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new dependency; the generator uses stdlib plus existing pinned imports. |
</threat_model>
