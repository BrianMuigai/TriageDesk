## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model output -> recovery edges | Invalid or partial model output must terminate safely, never be scored as-is. |
| serial vitals -> recheck | A second look is advisory; it must not mutate the queue. |
| out-of-scope input -> escalation | A paediatric/ambiguous case must not receive an adult colour. |
