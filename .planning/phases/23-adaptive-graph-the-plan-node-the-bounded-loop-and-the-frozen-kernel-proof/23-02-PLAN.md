# Plan 23-02 — The frozen-kernel structural proof

## Objective

Prove, structurally and offline, that the adaptive loop cannot widen what the system can do:
`finish_investigation` is the only door into `score`, the gate keeps one inbound edge, no
investigation node can write a clinical result, the action set cannot express a queue effect,
and the loop is bounded.

## DRY + SOLID

- **DRY** — the proof reads the *compiled* graph and the *declared* contracts; it re-declares
  no topology and no action list. `PlanAction` members are iterated, never re-listed.
- **SOLID: L** — the fake tools satisfy the same contracts the real tools return, so the proof
  exercises the shipped node bodies, not a copy.

## Tasks

1. **`tests/test_frozen_kernel.py` (new).**
   - (a) `predecessors("score") == {"finish_investigation"}` — computed from
     `graph.get_graph().edges`, no hand-written expectation of the rest of the topology.
   - (b) `predecessors("commit") == {"approval_gate"}` — unchanged.
   - (c) For each of the five investigation nodes, call the node with fake tools and assert the
     returned key set is disjoint from `{"priority", "commit_result", "handover"}`.
   - (d) `PlanAction` has exactly the four declared members and none of them is a kernel node.
   - (e) Budget: a fake `plan_next_step` that always proposes an admissible non-exit action
     cannot drive more than `MAX_INVESTIGATION_STEPS` decisions, and the run still ends at the
     gate; a repeated action is never offered twice; a spent budget reaches
     `finish_investigation`.
   - (f) The emergency arm executes `retrieve -> finish_investigation -> score` and never calls
     `plan_next_step`.

2. **`tests/test_merge_monotone.py` — ADAPT-07 proof.** Field-by-field: every `None` field is
   filled; every stated field wins; "extracted contradicts a recorded vital -> recorded wins";
   the complaint and the nurse-answer text are never overwritten; the returned case is a new
   value and the inputs are unmutated.

3. **Guard against drift.** Assert `missing_scored_parameters(case)` equals
   `scorer.score_priority(case).missing_vitals` across a matrix of cases, so the planner's
   projection and the scorer's report cannot diverge.
