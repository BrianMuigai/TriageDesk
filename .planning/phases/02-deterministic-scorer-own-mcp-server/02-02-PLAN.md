<objective>
Make discriminator matching a deterministic data lookup and apply the most-urgent-wins override to the scorer.

The matcher turns a complaint into ids from the closed discriminator set (or an explicit `no_match`) with no model and no fuzzy judgement; the scorer then raises the priority to the most urgent matched category. This closes the two biggest non-determinism and injection surfaces (Pitfalls 3 and 7) before Phase 3 wires anything to them.

Purpose: A flapping or LLM-assisted matcher swings the colour by two or more levels (Pitfall 7) and an injection that manipulates matching becomes under-triage (Pitfall 3). Both are closed here by making matching a pure alias lookup over `data/sats_discriminators.yaml`.
Output: `core/matcher.py`, the override in `core/scorer.py`, the `match_discriminators` MCP tool, and the matching/override/determinism tests.
</objective>

    - Each declared alias (case-insensitive, whitespace-normalised) resolves to exactly its discriminator id.
    - A complaint containing a known alias phrase (e.g. "chest pain", "fast breathing") returns that id.
    - A complaint matching nothing returns `no_match=True` with the declared warning and no ids — never a guessed id.
    - Ids returned are always members of the closed set from `data/sats_discriminators.yaml`.
    - Repeated calls on identical input return the identical `matched_ids` list (stable ordering).
  </behavior>
  <action>
Create `src/triagedesk/core/matcher.py` exposing a pure `match_discriminators(complaint: str) -> MatchResult`. It loads `data/sats_discriminators.yaml` through `core/rules.py` `get_discriminators()` and performs a deterministic, case-insensitive substring lookup of each declared alias against the complaint; it collects the ids of every discriminator whose alias appears, sorts the result deterministically, and returns `MatchResult`. When nothing matches, return `no_match=True` with the declared `no_match.warning` and an empty id list — never infer an id. The function must not call the model and must not import `llm|mcp|store` (D-02/D-05). Add `MatchResult` to `core/schema.py` (the ONE schema module, D-14).

  </action>
