## Locked decisions honoured here
- **D-01** `score_priority` is pure, lives in `core/`, reads bands from `data/sats_tews.yaml`, returns colour + tews + triggered_rules + citations + target time; **citations == triggered_rules**.
- **D-02** No number ever comes from the model; the scorer imports nothing from `llm|mcp|store` (enforced by `tests/test_purity.py`).
- **D-03** Out-of-scope fails closed: paediatric (age < 12 / height < 150 cm) or missing/ambiguous age abstains + escalates, never an adult colour.
- **D-04** Missing vitals are detected, never imputed; score inputs are a subset of nurse-provided fields (INTAKE-03).
- **D-09** One schema module, one citation helper, one rules loader (all from Phase 1) — reuse, do not duplicate.

## Interface contracts (executor reference)
- `core/rules.py` already exposes: `get_tews() -> TewsRules` with `parameters: dict[str, Parameter]`, `tews_to_colour: list[ColourBand]`, `target_times: dict[str, TargetTime]`, `out_of_scope: OutOfScope`; `Band` has `points`, optional `min`/`max` (inclusive), optional `value`.
- `core/citations.py` already exposes `format_citation(reference: str, source: str) -> str`.
- `core/schema.py` already exposes `CaseInput` (nullable, range-validated vitals) and `ExtractionResult`.
- New contract additions (the planner's default names — exact field names are the agent's discretion, but the invariant `citations == triggered_rules` is fixed):
  - `TriggeredRule`: `rule_id`, `detail` (human-readable "vital -> points"), `points`, `citation`.
  - `PriorityResult`: `colour`, `tews`, `target`, `destination`, `triggered_rules: list[TriggeredRule]`, `citations: list[str]`, `matched_discriminator_ids: list[str]`, `missing_vitals: list[str]`, `out_of_scope: bool`, `abstained: bool`, `reason`.
- **DRY trap:** the SATS strings (colour tokens, category names, target strings, destinations) and discriminating numbers already live in `data/*.yaml` and are scanned by `tests/test_no_duplicated_sats.py`. Never write a colour token or target string as a literal under `src/` — read it from the loaded data.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| typed case -> scorer | The scorer receives a validated `CaseInput`; values are treated as data, never as instructions |
| data YAML -> scorer | `data/*.yaml` is the only source of bands/thresholds/colours; the scorer inlines no scoring value |
| owned tool -> core | The MCP tool is a thin adapter over a pure function; it cannot inject a colour |
