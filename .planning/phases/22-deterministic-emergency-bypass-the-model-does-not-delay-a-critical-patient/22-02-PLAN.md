# Phase 22 · Plan 02 — Proof: the model is skipped, the kernel is not

## Objective

Prove the two halves of the bypass at once: the fast arm **cannot** wait for extraction, and it
**cannot** skip the safety spine. Record the bypass as a span/payload fact and publish the verdict.

## DRY / SOLID compliance (iron-clad, `docs/CONVENTIONS.md`)

- **DRY** — the proof suite reuses the ONE offline tool fake (`tests/conftest.py::build_graph_tools`)
  and the ONE span sink; it defines no second graph, no second tool map and no second scorer.
- **DRY** — the node-order expectation is derived from `TRACER_NODES` and the observed span order,
  never restated as a parallel hand-maintained topology.
- **SOLID:S** — the suite tests one property per test: extraction skipped, kernel executed, gate
  respected, normal arm unchanged, purity, audit.
- **SOLID:O** — no production module changes in this plan; the proof reads the shipped graph.
- **EMERG-05** — the audit event is the existing composition-root `_spanned` wrapper; the suite
  asserts it rather than adding a second writer.
