# Plan 25-01 — A modern chat desk, and a visible integration map

## Objective

Make the desk demonstrate the system instead of merely hosting it. The nurse gets a modern
conversation workspace beside the structured intake; the reviewer gets a `/system` page that shows
the three layers (desk → core → MCP), the transport at each hop, and the nine MCP tools. Fix the
three blockers the UI review found so the new surface cannot contradict the safety story.

## DRY + SOLID

- **DRY** — field labels/bounds come from `core.schema` + `desk.forms`; all dynamic copy lives in
  `desk.copy`; the SATS colours live in `styles.css`; the system page's tool list is checked by a
  test against the MCP server's own registered tools. No SATS band or threshold is restated.
- **SOLID: S** — `chat.py` renders transcript fragments; `system.html` is static presentation;
  `gate.py` renders the gate; `views.py` composes. No module scores, approves, or commits.
- **SOLID: O** — a new page is a new static fragment + one route, not a rewrite of the shell.
- **SOLID: L** — the desk's in-process tool map and the MCP server expose the same tool contracts;
  the system page states that shared surface instead of inventing a second one.
- **SOLID: D** — the desk depends on the graph/tool seams, never on `mcp.server`; the system page's
  tool list is verified from the test layer, where importing the server is allowed.

## Tasks

### Task 1 — Chat workspace and note intake

`type="auto"`

- Add `desk/chat.py`: escaped welcome/nurse/extraction/handover bubbles, no queue/commit imports.
- Restructure `index.html` into the rail + workspace shell; keep the vitals form and all safety
  controls. Add the composer associated with the vitals form (`form="vitals-form"`,
  `name="action" value="note"`) and keep it from disabling its own submitter.
- Add grouped fieldsets in `forms.py` while preserving `_VITALS_LAYOUT` order; add
  `merge_form_over_case` and `case_to_form_values`.
- In `server._handle_case`, branch `action=note`: offline sets the complaint; online calls
  `extract_note`, overlays only posted values, and prefills the form. Never run the graph or gate.
- Carry the paused case values into the gate form so the decision page repopulates the intake.

**Verify:** `uv run pytest -q tests/test_desk_chat.py tests/test_desk_forms.py`

### Task 2 — Fix the UI-review blockers and accessibility findings

`type="auto"`

- Gate: move the colour radios into a disclosure that submits `decision=edit`; Approve carries no
  colour; the server refuses an approve carrying a colour. Clear stale radios in the client.
- Autofocus: remove the vitals autofocus; focus the offending field on a schema error and the
  approver name on a rendered gate. Remove global smooth scrolling.
- Banner: suppress the uncertainty banner on clarification, recovery, and escalation terminals;
  keep it for a deferred read-only card.
- Accessibility/visual: 44px nav targets, distinguishable RED/ORANGE tokens, single waiting-room
  heading, humanized rule details and decision labels, and a responsive waiting table.

**Verify:** `uv run pytest -q tests/test_desk.py tests/test_desk_chat.py tests/test_desk_forms.py`

### Task 3 — The visible system / integration map

`type="auto"`

- Add `static/system.html` and `/system`: three layer cards (desk, core, MCP), the ordered wire
  (HTTP loopback → in-process tool map → MCP stdio JSON-RPC → borrowed SQLite MCP → handover),
  a shared/different table, the nine tools, and the "do not scrape the desk" integration note.
- Add the rail link and `aria-current`; keep the page loopback-only and read-only.
- Add `tests/test_system_page.py`: the page renders, names every layer and protocol, makes no
  external request, and its tool list equals `triagedesk.mcp.server.server.list_tools()`.
- Update `docs/DESK.md`, `docs/MCP.md`, and the README limitation line to point at the system page.

**Verify:** `uv run pytest -q tests/test_system_page.py tests/test_desk_runbook.py tests/test_no_duplicated_sats.py`

## Out of scope

- No new HTTP integration endpoint. MCP remains the station integration surface.
- No change to the scorer, matcher, retrieval, confidence, planner, graph topology, commit tool, or
  audit chain. The desk remains a presentation/demo surface.
