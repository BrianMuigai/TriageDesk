# Plan 24-03 — Answer the reviewer, honestly

## Objective

Turn the measurement into a defensible answer: the docs say what the system decides, prove
what it structurally cannot decide, publish the measured delta, and name every limit that
remains. The canonical architecture render is regenerated from the shipped graph, and the
security/docs status move from "proposed" to "shipped" only where the code exists.

## DRY + SOLID

- **DRY** — every number in `docs/AGENTIC.md` is a link or a quotation from `EVALS.md`
  (itself generated from `report.json`); the doc restates no figure as an independent source.
  D31–D34 record rationale once; ARCHITECTURE and STATUS link rather than re-argue.
- **SOLID: S** — one document per question: AGENTIC answers the reviewer; ARCHITECTURE the
  shape; EVALS the measurement; STATUS the gap analysis; SECURITY the threat model.
- **SOLID: O** — the docs add a section, not a second evaluation pipeline; the generator is
  unchanged by the docs.
- **No SATS value is restated**: AGENTIC names the tool that owns the threshold, never a band.

## Tasks

### Task 1 — `docs/AGENTIC.md`

`type="auto"`

Write the reviewer-facing answer in this order: the challenge quote → what the system decides
(and where) → what it structurally cannot decide (closed action set, one edge into `score`,
one edge into `commit`) → the measured adaptive-vs-baseline delta (linked to `EVALS.md` §3.3,
stated even if zero/negative) → the emergency bypass as the counterweight → the honest limits
(bounded actions, no free-form planning, CPU-model proposals, elicitation answered by a client
that can decline). Link it from `README.md` and `ARCHITECTURE.md`.
