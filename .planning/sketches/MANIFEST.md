# Sketch Manifest

## Design Direction

A calm, modern clinical workspace: a dark orientation rail, a light canvas, one primary task per
state, and a structured intake that stays visibly authoritative. Teal is the action colour; the SATS
swatches remain the only clinical colour language.

## Reference Points

- Modern triage / patient-workspace dashboards: a rail for orientation, one primary working area.
- Hybrid conversational forms: a note helper beside a complete form, not a competing second intake.
- Clinical safety surfaces: explicit suggestion framing, named approval, evidence beside the claim.
