    - A one-time setup fenced bash block (`uv sync --locked`).
    - The literal one-command path: `uv run triagedesk desk`, plus the `--host`, `--port` and `--db` overrides,

      suggestion` / `Edit colour` / `Dismiss (commit nothing)`), the banner headline, and the committed /
      dismissed / timeout copy.
    - A short plain-language "what the surface never does" block naming the fail-safe rules: a timeout is no
      approve; a dismiss commits nothing; the surface never commits on its own — the only route to the queue
      is your own approval through the gate.

      (D10-14). Keep it to one screen.
    (b) Create `tests/test_desk_runbook.py` mirroring `tests/test_demo_runbook.py`. The guard drives the
    shipped CLI through its **public `main` surface** — the same entry point the console script calls,
    exactly as `tests/test_demo_runbook.py` does — never by importing a private parser helper:
    - Read `docs/DESK.md`, extract the fenced command blocks with a regex, and collect every `triagedesk desk`
    invocation they contain (strip the `uv run triagedesk ` prefix to get the argv the console script
    receives). Monkeypatch the `triagedesk.desk.server.serve` attribute with a spy (the lazy-import target
    inside `main`, so the monkeypatch must be on that module attribute, not a name in `cli`'s namespace) and
    call `main(argv)` for each documented invocation; assert each returns 0 and the spy recorded it — so the
    runbook cannot document a flag the shipped CLI rejects, and no server is actually started.
    - Assert the document names the literal `uv run triagedesk desk`.
    - Assert the fail-safe clauses are present (a timeout clause, a dismiss clause, and a "never commits on
      its own" clause), so the runbook cannot drift into over-claiming.
    - Assert the document names no internal identifier: derive the check set from
      `triagedesk.graph.build.TRACER_NODES`, keep the entries containing an underscore (the identifiers no
      runbook should ever name), assert that filtered set is non-empty, and assert none of them appears in the
      document; also assert the document does not carry a thread-id token. Import the tuple — never restate
      the node names.
    - Keep every assertion non-vacuous (assert the extracted command set and the filtered identifier set are
      both non-empty before asserting absence).
