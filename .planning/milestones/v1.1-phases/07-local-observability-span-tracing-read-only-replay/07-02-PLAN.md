<objective>
Add ONE read-only replay path that reconstructs a past case from the LangGraph checkpoint plus the
audit/span stream, and expose it as `triagedesk replay --thread-id <id> [--db PATH]`.

Purpose: satisfy ROADMAP Phase 7 success criteria 3 and 4 by construction — replay reads stored data
only, builds no tool map, and therefore can never re-run the gated commit or the model.
Output: `src/triagedesk/replay.py`, the `replay` CLI subcommand, the zero-write/no-model proof suite,
and the recorded decision + security note.
**CONTEXT decisions implemented:** D7-09, D7-10, D7-11, D7-12, D7-13, D7-14, D7-15, D7-16 (and the
resolved orchestrator decision that `--db` names the checkpoint DB, with the audit store resolved
through the existing `mcp.server._resolve_store` seam).

**User story (ROADMAP Phase 7 Goal):** **As a** triage-nurse reviewer, **I want to** re-examine what a
past case did and decided — without the system doing anything again — **so that** I can audit a triage
decision safely, with zero risk of a second queue write.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| checkpoints.db → replay process | The desktop file is untrusted input to the deserialiser. |
| replay → queue/audit store | Replay must be a pure read; it must never reach a write. |
| stored audit/span stream → rendered view | A tampered stream must not mislead the reviewer into a false outcome. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-05 | Tampering / Repudiation | replay re-executing the gated commit | high | mitigate | `replay.py` builds NO tool mapping and compiles NO graph, so `commit_priority` is structurally unreachable; the zero-write test proves zero queue rows and zero `commit_priority` records after replay. |
| T-07-06 | Tampering / Elevation | `AsyncSqliteSaver` deserialiser over a tampered `checkpoints.db` | high | mitigate | The saver's serde is `JsonPlusSerializer(allowed_msgpack_modules=_allowed_msgpack_modules())` — the ONE derived allowlist, never `True`. |
| T-07-07 | Repudiation | replay becoming a second, unaudited write path | medium | mitigate | Replay calls only read-only store methods (`read_audit_records`, `read_queue_rows`); no append/upsert/commit import appears in `replay.py`. |
| T-07-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package (no new dependency); no legitimacy gate is required. |
</threat_model>
