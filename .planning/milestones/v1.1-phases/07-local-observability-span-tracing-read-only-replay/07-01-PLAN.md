<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| complaint note → node/model span | Untrusted clinical text is in scope at the model boundary; it must not enter the sink. |
| process env → transitive tracer | `LANGSMITH_*`/`LANGCHAIN_TRACING*` decide whether LangChain egresses. |
| audit record → borrowed SQL | The record shape and the SQL column list are separate sources of truth (the silent-drop pitfall). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Information Disclosure | transitive LangSmith/OTLP tracer (`observability/offline.py`) | high | mitigate | `harden_offline()` pops the four tracing vars AND calls `langsmith.utils.get_env_var.cache_clear()`, then asserts `tracing_is_enabled() is False`; OTLP is inert (no SDK). |
| T-07-02 | Information Disclosure | span sink (`observability/spans.py` emit sites) | high | mitigate | Span attributes are minimal (ids, kind, timings, colour/rule ids, token counts); the model span carries the model tag + `(prompt_eval_count, eval_count)` only — never the note/prompt/completion (D7-08). |
| T-07-03 | Tampering / Repudiation | `AuditRecord.trace_id` | medium | mitigate | `trace_id` is content-derived (`case_id_for`) and sealed inside `record_digest`, so a forged id breaks the chain digest rather than silently mis-joining a record to spans. |
| T-07-04 | Elevation | `graph/*.py` env/credential read | high | mitigate | All env logic stays in `observability/offline.py` (outside `graph/`); `graph/build.py` imports only the span context/writer, so `test_safety_spine.py::test_graph_reads_no_credentials` stays green. |
| T-07-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no package (no new dependency); no legitimacy gate is required. |
</threat_model>
