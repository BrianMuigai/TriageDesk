<objective>
Deepen the borrowed SQLite MCP usage from `query`-only to its real read paths, behind the unchanged
`Store` protocol, and make the borrowed server provably read-only on the agent path with a tool allowlist
plus a fail-closed statement guard.

Purpose: MCP-01 is an integration claim, not a wiring claim. It only holds if the read tools are actually
invoked (`store/borrowed.py` already declares the constants but never calls them) AND if a mutation
presented on that path is refused before it reaches the borrowed server. Because the real
`mcp-sqlite@1.0.9` argument shapes for `read_records`/`get_table_schema` are unverified in-repo, every read
path must also degrade gracefully rather than crash the store-open path.
Output: the guarded `_call` seam, `READ_TOOLS`, `is_read_only_statement`, the `ensure_schema` read-path
probe with a recorded report, and the MCP-01 proof suite.

**CONTEXT decisions implemented:** D9-11, D9-12, D9-13, D9-14.
</objective>

<assumption_delta_decision>
**A1 (`read_records`/`get_table_schema` real wire shapes unverified) — decided: degrade, do not probe live.**
All four read paths are implemented at the ONE guarded seam, but their results are consumed defensively:
the probe records a degradation on any shape surprise instead of raising, and no existing verified `query`
read is rerouted through the unverified tools. MCP-01 is therefore proven hermetically against the suite's
stdlib-`sqlite3` stand-in, which observes the read tools being called; the phase does NOT block on a live
`npx` borrowed-server probe and adds no human-verify checkpoint. If the recorded report shows a degradation
during the pre-demo real run, that is visible evidence to act on then, not a hidden failure.

**Pitfall 3 — decided: keep the PRAGMA `trace_id` check.** The column-existence check stays on the
verified `PRAGMA table_info(...)` read; `get_table_schema` is used additively by the probe only. Switching
the check to the stand-in's column-less schema response would issue a duplicate-column ALTER.

**`ensure_schema` probe cost — accepted.** Four extra borrowed round trips per store open is the price of
"used, not merely declared" with the fewest new surfaces; it runs after the DDL and cannot fail the open.
</assumption_delta_decision>
