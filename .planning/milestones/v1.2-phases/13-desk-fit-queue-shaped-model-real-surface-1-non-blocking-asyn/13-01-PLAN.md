<objective>
Make the model call asynchronous and give the desk surface ONE persistent event loop.

Purpose: today `llm/client.py:105` calls `ollama.generate(...)` synchronously inside an async graph node, so
every extraction blocks the event loop for its full latency (measured p50 13.06 s), and
`desk/server.py:263-275` calls `asyncio.run(...)` per POST inside a `threading.Lock`, creating and destroying
a loop per request and pinning an OS thread for every submission. This plan adds the ONE async extraction path
behind the existing client interface (same prompt, same parser, same grounding), makes the owned
`normalize_case` tool await it, and replaces the per-request loop with a loop the server owns for its whole
lifetime.

Output: `extract_async` + the shared extraction core, an async `normalize_case`, an updated usage seam, the
`desk.loop.DeskLoop`, the re-wired desk handlers, and the concurrency proofs.

**Safety argument.** Nothing in this plan touches the graph topology, the tool allowlist, the hash-chained
audit, the deferral rule, the commit path or the approval gate. `normalize_case` still returns the same
`ExtractionResult` and still filters model ids to the closed discriminator set; the scorer still owns every
colour and every citation. The async transport changes *when* the model answer arrives, never *what* is done
with it — no new path can reach `commit`, and no new path can emit an uncited colour.
</objective>
